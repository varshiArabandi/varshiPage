# Varshi Threading & Wax Bar

Static website for Varshi Threading & Wax Bar, North York.

## Edit in IntelliJ IDEA

This is a plain HTML/CSS/JavaScript project. No Maven, Node.js, or build step is required.

Open the project folder in IntelliJ IDEA and edit:
- `index.html` — website text, services, prices, links
- `styles.css` — colors, fonts, spacing and layout
- `script.js` — small interactive behavior
- `logo.jpg` — logo
- `services-menu.jpg` — service menu image

## GitHub Pages

The included GitHub Actions workflow deploys the website automatically whenever you push to the `main` branch.

After enabling GitHub Pages with **GitHub Actions** as the source, the site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/`

## Local preview

In IntelliJ, right-click `index.html` and choose **Open in Browser**.
